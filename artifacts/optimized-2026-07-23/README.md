# Optimized run

This run uses the same requested date window and active source list as the
unmodified baseline, after the data-quality and source-adapter improvements.

## Experiment

- Run date: 2026-07-23
- Requested window: 2026-06-23 through 2026-07-23
- Location: all Japan
- Keywords: none
- Employment type: unrestricted
- Page limit: 2
- Sources: the 10 sources marked `active`
- Detail enrichment: enabled
- Unknown dates: excluded

```bash
jpjobs \
  --sources=hellowork,linkedin,tokyodev,japandev,daijob,gaijinpot,jobsinjapan,green,forkwell,wantedly \
  --days=30 \
  --as-of=2026-07-23 \
  --pages=2 \
  --fetch-details \
  --rate-limit=700 \
  --format=json \
  --output=artifacts/optimized-2026-07-23/jobs.json
```

## Pipeline results

- 641 raw listings fetched.
- 240 listings were confirmed to be older than the requested window.
- 1 listing had no recoverable posted date and was excluded.
- 3 cross-source listings were merged.
- 397 verified in-window jobs remained.

All active source list scans completed successfully. Detail enrichment completed
without HTTP errors; one Daijob page did not expose structured job data.
